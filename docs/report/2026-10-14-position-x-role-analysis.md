# 2026-10-14 ネットワーク位置 × X による行動分化

## 結論

既存９runでは、フォロワー数に応じたRESHAREへの偏りは明瞭である。Xによる違いも観測されるが、「端ほどPOSTする」という単調な分化は確認できない。η=0.03のseed平均では中間帯がPOSTを多く、中央帯と端がRESHAREを多く選ぶ。ただしX差の符号がseed間で逆転する層があり、特に高入次数の小標本セルは不安定。η=0.01のフォロワー5–19人層では中間帯のPOST増加が３seedで揃う。現段階は位置とXに条件付けた政策の記述であり、効用上の最適な役割分化を証明したものではない。

## 対象・分類・集計

- 対象：η=0.1 / 0.03 / 0.01 × seed=0 / 1 / 2、n=1000、各20,000 step。既存のeta_noise_compareの９本を再分析し、新しいシミュレーションは行っていない。k=20、rewire off、状態なしbandit、その他条件は同実験manifest参照。
- 評価窓：step 15001–20000。各個人の行動割合をセル内で等重み平均し、run別セル値を３seedで等重み平均。
- ネットワーク位置：フォロワー数（入次数）を0 / 1–4 / 5–19 / 20–49 / 50+に分類。ネットワーク上の位置の一側面であり、中心性全般やコミュニティ位置ではない。
- X：中央帯 |X|<1/3、中間帯 1/3≤|X|<2/3、端 |X|≥2/3。符号別には左中間・右中間・左端・右端と中央帯を使う。閾値依存の確認として |X|<0.25 / 0.25≤|X|<0.75 / |X|≥0.75 も集計。
- Xはmu=0で不変。最終snapshotのopinionとintrinsicOpinionが全9000 agent-runで一致し、各seedでηを変えても同じ個人のXと次数が一致することを確認。Xはsnapshotの４桁精度を使用するが、主要閾値の±0.00005以内の個人はゼロ。
- 各seedの辺集合もη間で一致。LIKE/RESHAREによるfollowee queueの並べ替えがあるため、CSV行順を除去した辺集合で照合。
- 個人内報酬差：両行動30更新以上の個人について行動別平均報酬の差を取り、セル内中央値、その後seed平均。状況と履歴を揃えた因果効果ではない。小セルの少数のeligible agentに依存する値は断定に使わない。
- 持続性：末尾窓を前後2500 stepに分け、両側30訪問以上の個人について最多行動が一致する割合。有限標本や固定環境の影響を含む。

## η=0.03：位置 × X の行動割合

各セルは **POST / LIKE / RESHARE (%)**。四捨五入で合計が100にならない場合がある。

| フォロワー数 | 中央帯 | 中間帯 | 端 |
|---|---:|---:|---:|
| 0 | 29.3/37.1/33.6 | 34.2/33.4/32.4 | 33.9/34.8/31.3 |
| 1-4 | 29.5/31.8/38.7 | 33.8/30.0/36.3 | 32.1/29.7/38.2 |
| 5-19 | 24.8/16.6/58.6 | 31.9/16.0/52.1 | 26.7/14.4/58.9 |
| 20-49 | 23.2/9.9/66.9 | 32.6/15.8/51.7 | 24.0/14.6/61.4 |
| 50+ | 18.3/8.6/73.1 | 28.2/15.3/56.5 | 20.1/8.7/71.1 |

次数が5以上の層では、中間帯のPOSTが中央帯より平均で約7–10ポイント多く、RESHAREは約7–17ポイント少ない。中央帯と端は互いに近い。したがって、このηのseed平均は中心から端へ単調に変わるという形ではない。

## seed別の再現性とη依存

η=0.03の50+層では、POSTの中間帯−中央帯差はseed 0 / 1 / 2で **−13.6 / +4.3 / +39.1ポイント**。平均+9.9ポイントだけでは安定したX効果と言えない。5–19人層でも **−5.3 / +8.9 / +17.7ポイント** と符号が揃わない。

η=0.01の5–19人層では、中間帯−中央帯のPOST差が **+12.7 / +7.6 / +18.8ポイント** と３seedで正。全体でも+6.4 / +2.8 / +10.8ポイント。一方、20–49人や50+層では一部seedの差が負である。η=0.1では全体の中間帯−中央帯POST差も −3.9 / +5.7 / +0.9ポイントと不安定。

| η | 中央帯 POST/LIKE/RESHARE | 中間帯 POST/LIKE/RESHARE | 端 POST/LIKE/RESHARE |
|---|---:|---:|---:|
| 0.1 | 29.3/27.6/43.1 | 30.2/28.2/41.6 | 28.9/29.3/41.9 |
| 0.03 | 27.2/26.5/46.3 | 32.9/25.4/41.7 | 29.8/25.1/45.1 |
| 0.01 | 30.3/28.1/41.6 | 37.0/25.2/37.8 | 30.1/27.1/42.8 |

最少ηでの一部のX差は再現するが、η全体に普遍的な役割分類とは言わない。今回は３seedのpilotであり、学習なしのnull比較や推測統計による効果の検定は行っていない。

## 左右を分けた場合

η=0.03の50+層では、左端と右端に大きな差がある。

| X帯 | POST/LIKE/RESHARE (%) | セルの最少人数/seed | 平均フォロワー数 |
|---|---:|---:|---:|
| 左端 | 32.1/15.0/52.9 | 6 | 194.7 |
| 右端 | 10.8/4.7/84.5 | 8 | 222.6 |

この左右差をモデルの一般的性質とは解釈しない。高次数セルは片側6–8人まで小さくなるseedがあり、同じ次数区間でも正確な次数分布・近隣配置は一致していない。|X|だけでまとめると、この初期配置を含む左右差が隠れる。全体集計では左右差は小さく、右端RESHARE45.4%、左端44.9%である。

## 研究上の読み方と次の比較

現在のモデルでは、主にフォロワー数で再共有への配分が分かれ、その中にXと初期配置に依存する違いがある。「中央の人は消費者、端の人は投稿者」のような固定的な対応は今回のデータでは支持されない。特に周辺層は全X帯でほぼ混合政策であり、役割として特化する段階には達していない。

次は、この二軸のセルを固定して①学習なしの等Q政策、②現在の学習、③行動に帰属する報酬と制作/消費の得失を明示したモデルを段階比較する。各段階で位置×Xの行動割合、同じ個人の行動変更による利得差、長期持続性を確認する。セルの平均だけを目的関数として分化を強める変更は行わない。
