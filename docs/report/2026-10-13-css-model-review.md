# 2026-10-13 CSS・実装・新規性レビュー

評価対象は `attention-economy` ブランチの未コミット変更を含む現行 Java コード。旧 CNA2026 の moderate-conduit モデルは対象外。10月13日の静的ネットワーク版と、新設された推定プロフィール型 For You を主対象とし、再配線オンの場合も確認した。モデル本体や既存結果は変更していない。

**総評：推薦とユーザー行動の相互作用を調べる機構モデルとして有望。ただし、現時点で「推しへの没入・習慣形成を説明する新モデル」や「アルゴリズムが注意格差を生むことを実証したモデル」としては未完成。学習と再現性に関する不具合を先に直し、推薦・供給・初期ネットワークを分離して検証する必要がある。**

## 1. 現在実装されているモデル

- 各人の固定値 (X_i\in[-1,1])、行動ごとの9状態×4行動のQ表、存続する自分の投稿がある。基準条件の `mu=0` では X は変化しない。
- 訪問時に post / like / reshare / rewire から1つ選ぶ。`rewire=false` では3行動。訪問確率は外生的。
- 状態と報酬は「フィード内投稿との平均類似度」と「存続する自分の投稿へのいいね数の飽和関数」。最新の承認報酬は指数関数と対数関数の混合であり、初期仕様の純対数関数から変わっている。
- chrono は前回訪問後に受信した有限キャッシュからの標本。Trend は再共有速度による順位。For You は反応から更新する推定値 X̂ と投稿内容との類似度による重み付き抽出。
- 再共有は投稿内容をコピーした新規投稿で、その後のいいねは再共有者の承認になる。元投稿は再共有で寿命が延びるが、元作者の承認に再共有数は入らない。
- 投稿は最後のいいね・再共有から L ステップを超えると消える。
- 現行の再配線は **フィードに出た投稿の root author を候補にし、旧フォロー先より近い場合だけ交換**。仕様 rev 9 の2-hop候補から既に変わっている。

`docs/research-direction.md` の「内生的 intensity」「習慣・依存形成」はこのコードでは実装されていない。Q表の変化だけでは、対象への愛着や習慣の形成を測ったことにならない。

## 2. 確認できた不具合と修正優先度

### B1 — 高：Bellman更新が選択不能な行動を含む

場所：`src/agent/Agent.java:194`–198。選択時には action mask を使うが、次状態の `max Q` は4行動すべてから取る。

`rewire=false` でも未更新の rewire 列が参照される。空フィードでは like / reshare の値も参照される。最新実験の `q_init=7` では、利用可能な行動の値が7未満の状態で、選べない rewire が学習目標を支える。初期値0でも空フィード側の問題は残る。

追加プローブでは、選択不能な rewire のQを100、利用可能な行動を0に置くと、報酬1・η=1・γ=.9で更新値が **91** になった。正しく mask した値は **1**。空フィードでも同様に90対0を再現。

修正：行動可用性の判定を共通化し、次状態の最大値にも適用する。利用可能な行動が0の場合の扱いも定義する。既存テストは更新則と可用性を別々に確認しており、その組み合わせをカバーしていない。

### B2 — 高：実験設定が保存されず、異なる設定が同じ出力先になる

場所：`src/experiment/InterventionSetup.java:109`、`ExperimentConfig.tag()`、`OpinionDynamics.main()`。

`run_config.csv` は介入したハブごとに書くため、通常の介入なし実験では **ヘッダーだけ**。現存の `fyexp_*` 結果でも確認した。介入がある場合も、For You、Q学習、承認関数など多くの設定は保存されない。フォルダ名には非デフォルト値だけが入り、後日デフォルトが変われば復元できない。

さらに `interaction_window=100` と200が同じ出力先になること、`q_tau=.1001` と.1002が小数丸めで同じ出力先になることを再現した。介入ID、pin値、read_path等もタグから欠落する。衝突時のABORTは `return` なので終了コード0となり、実験ドライバが成功と誤認しうる。これは既存OPERATIONSにも記録された問題だが、現行実験にも残る。

修正：全設定、明示的CLI、デフォルト、コードの版・dirty状態、seed、スキーマをrun単位で保存する。出力IDは全設定の正規化ハッシュを使い、衝突・I/O失敗は非0で終了する。

### B3 — 高：同じ人が同じ投稿に何度もいいねできる

場所：`src/agent/Agent.java:286`付近の `like()`、`src/agent/Post.java:94` の `like()`、`AdminOptim.selectForYou()`。

いいね済みuser–postの履歴がなく、同一人物が同一投稿に2回いいねすると、いいね数が2になり、寿命も再更新された。For You / Trend は存続する投稿を再び提示できるので、通常経路で起こりうる。

SNSの「いいね」を表すなら不具合。反復消費や応援クリックを意図するなら、その行動名・データとの対応を改める必要がある。反復反応が承認・存続・推薦へ戻るため、単なるカウンタの問題ではなく、注意集中の結果にも関わる。ただし、この問題が実際の集中度をどれだけ押し上げたかは未測定。

修正：いいねの一意性をuser–post単位で保証する。再共有の反復可否は別に決める。閲覧の再提示を残すなら、再提示と再反応を区別して記録する。

### B4 — 中：利用可能な行動が0だと、例外または禁止行動

`rewire=false`、channel NONE、空フィードで再現。探索分岐は `nextInt(0)` で例外。探索なしではデフォルトのPOSTを返し、投稿禁止を破る。通常の介入なし条件には直結しないが、`silent_until_ids` や channel介入には影響する。

修正：明示的なno-opを定義し、その訪問をどう学習・集計するか決める。

### B5 — 中：計測・検証の抜け

- `StepStats.outGroupExposureCount` は計算されるが、`buildMetricsRow()` からCSVへ出ていない。10月13日の実験計画にあるout-group exposureは現行結果CSVから直接取得できない。分母の提示投稿数とともに出力する必要がある。
- `AssertionCheck.reportASError()` は `i < maxStep` のため最終ステップの違反を集計しない。また意見の範囲比較ではNaNを検出できない。assertion 0件は有限値・学習・生存期間の正しさを保証しない。
- `Agent.updateValues()` は `setStubbornness(1)` を参照しない。`mu>0` で完全固定とされたハブも動きうる。基準条件mu=0では顕在化しない。
- `SimParams.from()` はフィードshare以外の範囲検証がほぼない。γ≥1、l_ref=0、NaN、逆転したstate境界などが通る。未知キーも黙って無視するため、旧校正スクリプトは撤去済みパラメータを変えても同じ実験を実行しうる。

再配線オンでは、hop到達集合の100ステップキャッシュも現在の辺と一致しない期間がある。静的版には影響しない。これは高速化の近似として明記し、キャッシュ更新間隔への頑健性を確認する必要がある。

## 3. CSS研究としての妥当性

### 学習則は説明候補として妥当だが、人間行動の実証モデルにはまだ足りない

SNS上の社会的報酬による投稿行動の学習には実証的基盤がある。Lindströmらは複数データと実験を用いて検討している。2026年のTurnerらはTwitterの2,696人を分析し、強化学習と習慣過程の混合モデルを支持した。これらは「人間をQ学習で表す」という選択を支えるが、現在の9状態・3/4行動・等重み報酬を直接検証したものではない。[Lindström et al., 2021](https://pmc.ncbi.nlm.nih.gov/articles/PMC7910435/)、[Turner et al., 2026, 著者所属大学の公開版](https://www.repository.cam.ac.uk/items/version/1506)。

特に、ここではlikeが他者の承認を増やしても、自分の即時効用には入らない。静的ネットワークでも推定プロフィールへの作用はあるが、純粋な楽しさ、関係維持、互恵性等は表さない。したがって「likeのQが低い」は人間の消費選好の発見とは限らず、報酬の構成から生じうる。これはglobal rewardを採用した設計選択であり、B1とは別問題。

一方、**globalな状態報酬だから全行動のQが必ず等しくなる、とは言えない**。行動が異なる遷移を生めば、その長期価値は異なる。値の差が小さい原因には、状態の粗さ、報酬遅延、行動による効果の弱さ、学習過程、B1等がある。学習が収束していないことだけから「現在のQ差は真の差の下限」とも言えない。

### 状態は強く情報を落としており、収束や最適性を主張しにくい

同じ適合度・承認binでも、自分の投稿数と年齢、フォロワー数、候補投稿、推定プロフィール、誰が反応できるかで次状態が変わる。環境も他者の学習で変化する。状態は部分観測・非定常な社会状況の粗い代理であり、定常Markov環境での通常のQ学習の保証をそのまま使えない。

これはABMとして禁止される構成ではない。「限定された情報で学ぶ人間の仮説」として位置付け、Q学習以外の単純な行動則でも主要結果が出るか確かめるべき。状態条件付きの個人Q差、更新回数、政策エントロピー、時間窓ごとの政策変化を記録する。全9状態の平均Qには未訪問状態も混ざるので、学習の診断として弱い。

### 注意・反応・承認・没入は別の変数

現在の `attnGini` は作者が受けた **累積いいね＋再共有** のGiniで、閲覧・視聴時間のGiniではない。個人が特定作者に集中することと、集団全体が少数作者に集中することも別。

必要な追加観測は、作者別の提示・選択・一意な反応、直近窓の受信反応、各ユーザーの対象別消費shareとHHI/entropy、対象変更率、反応の相互性、creator継続率。累積Giniだけでは、最近の集中変化やcreatorの交代を隠す。

訪問確率は外生、idle/読むだけはなく、投稿といいねには同じ1行動枠を使う。したがって総滞在時間・参加量の増加や離脱、投稿制作コストを扱うモデルではない。`postsPerVisit` は生成物数/訪問数で通常0〜1に収まり、反応需要に対する供給過剰の指標にはならない。供給/反応は `(post+reshare)/(like+reshare)` 等で別に測る必要がある。

### アルゴリズムの処置をもっと正確に定義する必要がある

chronoは時系列順の閲覧を再現しておらず、FIFOキャッシュからrootを重複除去して無作為抽出し、訪問後にキャッシュを全消去する。一方、For Youは全存続投稿のバックログを再利用できる。hop1同士でも **順位付けだけでなく候補集合・再提示機会・実際のフィード充填数** が変わる。

また個人プロフィールの初期化とネットワーク生成・queue初期化が同じRNG streamである。fy_profile=true/falseは消費する乱数が異なり、動的実験では下流の乱数も分岐する。同じseedを使っても全過程の共通乱数比較にはならない。現行WS/DBAの初期Xと辺はこの初期化前に作られるため、その初期状態の比較まで無効になるわけではない。

プロフィール更新は提示された投稿への反応に基づく。`estError` の改善だけでは推定器の妥当性を示せず、アルゴリズムが自分で与えた選択肢から学ぶ選択バイアスも調べるべき。推薦フィードバックによる行動の同質化自体は既存研究で扱われている。[Chaney et al., RecSys 2018](https://arxiv.org/abs/1710.11214)。

### 初期ネットワーク効果とアルゴリズム効果を分離する

WSとDBAはin-degree格差だけでなく、クラスタリング、到達性、形成順序が違う。DBAでは後発ノードが既存ノードをフォローし、初期核以外は形成順序に沿う有向構造になる。hop拡大の効果にはこの階層性も混ざる。

「DBAで集中が高い」は初期条件の妥当な結果だが、それだけでは内生的な集中発生とは言えない。同じネットワーク上の処置差を主に報告し、degreeを保ったランダム化などで構造の寄与を分ける。

### 1次元の類似度には中道の構造的優位がある

一様な投稿値Yに対して、固定値xの平均適合度は

\[
E[1-|x-Y|/2]=(3-x^2)/4.
\]

中央x=0で.75、端x=±1で.50。推薦や学習の前から同じ環境への報酬が違う。価値位置別の結果を「アルゴリズムの効果」と読む前に、その位置に対する無作為露出の基準を引く。これを保つか変更するかは理論上の選択であり、コードバグではない。

## 4. 2025–2026年研究から見た位置付けと新規性

| 近い研究 | 既に示されていること | このモデルに求められる差分 |
|---|---|---|
| Turner et al., Nature Communications 2026 | 投稿に対する強化学習と習慣の混合を実データで検討 | 習慣の存在自体を新規性にせず、推薦下で行動役割が分かれる仕組みを示す |
| Gauthier et al., Nature 2026 | Xで推薦をオンにした効果とオフにした効果が非対称。推薦を契機にフォローした相手が残る経路を報告 | 推薦の履歴、ネットワーク変化、ユーザー学習を切り分けた持続効果を予測する |
| Brady et al., Nature 2026 | 自作ランキングの8週間実験で露出・規範認識・利用体験を比較 | フィード適合度だけで厚生や現実性を判断せず、複数outcomeと比較する |
| Ye et al., CreAgent / SIGIR 2025 | creatorの応答・情報の非対称性を含む長期推薦評価 | creator応答の導入自体より、単純な規則で説明できる機構を示す |
| Buhayh et al., 2025 preprint | 推薦選択とプロフィール可搬性がconsumer/providerの公平性へ及ぼす効果をシミュレーション | 推定プロフィールの誤差・更新が両側の格差へどう作用するかを特定する |

上表の根拠：[Turner et al.](https://www.repository.cam.ac.uk/items/version/1506)、[Gauthier et al.](https://www.nature.com/articles/s41586-026-10098-2)、[Brady et al.](https://researchportal.hkust.edu.hk/en/publications/redesigning-algorithms-to-intervene-on-social-norm-misperceptions/)、[CreAgent](https://arxiv.org/abs/2502.07307)、[Buhayh et al.](https://arxiv.org/abs/2509.22660)。preprintは査読済み実証結果と区別する。

推薦による注意格差という問いそのものにも、Weiboの自然実験を使った先行研究がある。[Li et al., ICIS 2019](https://researchportal.hkust.edu.hk/en/publications/how-does-algorithmic-filtering-influence-attention-inequality-on-/)。

**強く主張できる新規性候補**は「供給と消費を同じ行動予算から学ぶユーザー」と「その反応からプロフィールを学ぶ推薦器」の二重フィードバックが、初期構造と投稿忘却のもとで、creator/supporterへの役割分化や集中の持続を生む条件の特定。この組み合わせの実装は研究の土台にはなるが、組み合わせただけでは理論的貢献が確立しない。

現時点では、役割分化を個人の持続的政策として測っておらず、習慣/intensityもないので、この主張はまだ実証されていない。文献調査も完全な網羅検索ではなく、世界初を保証するものではない。

政治分極化へ戻る場合も、「推薦は分極化を起こさない」という一般化は避ける。2025年のX実験は敵対的内容の再順位付けで感情的分極化の変化を示し、2026年のX実験は政治的態度の変化と感情的分極化を区別している。現在のX固定・hostilityなしのモデルはその両者を同じように検証できない。[Piccardi et al., Science 2025](https://culture-emotion-lab.stanford.edu/sites/culture_emotion_lab/files/media/file/science.adu5584.pdf)、[Gauthier et al., 2026](https://www.nature.com/articles/s41586-026-10098-2)。

## 5. 現存データから言えること

完了済みWS各3 seedについて、各runのステップ15001〜20000を平均し、seedを等重みで集約した。Giniとtop shareは各時点までの累積反応指標。条件はフォルダ名・設計記録から確認したが、B2のためrun単位の完全設定は復元できない。

| WSの処置 | 平均適合度 | 平均承認 | 累積反応Gini | 上位1%反応share | post / like / reshare |
|---|---:|---:|---:|---:|---|
| chrono | .651 | .168 | .152 | .018 | .490 / .161 / .349 |
| For You hop1・推定値 | .784 | .235 | .259 | .026 | .387 / .206 / .407 |
| For You hop1・真値 | .801 | .240 | .264 | .026 | .381 / .212 / .407 |
| For You hop2・推定値 | .793 | .227 | .253 | .029 | .391 / .194 / .415 |

**適合度の向上と反応集中の増大が同時に起きる**ことは、検証する価値のある現象。ただし現在の差にはバックログ・再提示・供給反応・B1/B3も含まれる。「類似性推薦単独の効果」「一般的な厚生改善/悪化」とはまだ言えない。3 seedは探索用で、時点を独立標本として有意差を主張しない。

読み取り時点ではDBAのchronoは3 seed完了、For You hop1は途中であり、DBA処置間の最終比較は行わなかった。元データは実行中に変化しうるため、読み取った要約を添付CSVに保存した。

## 6. 次に行うべき検証

優先順は次のとおり。

1. **B1/B2/B3を修正し、無行動時の処理と有限値検証を追加。** 修正前後で同じ条件を再評価する。既存結果を即廃棄する必要はないが、主要結論の根拠には修正後結果を用いる。
2. **推薦の比較を分解。** 同じalive候補・寿命・枠数・root dedupを持つ無作為バックログ抽出（fy_beta=0）を追加する。chronoとの比較でバックログの効果、beta=0との比較で類似性選択の効果を分ける。実際のfeed充填率・再提示率・候補数も出す。
3. **学習の必要性を確認。** η=0かつ等Qの政策、固定確率政策、現行学習政策を比較する。空フィード等の制約があるため、η=0でも全行動が常に等確率という期待は置かず、利用可能集合内の等確率を確認する。
4. **二重フィードバックを分離。** 真値プロフィール、更新しない初期プロフィール、反応で学ぶプロフィールを比較。訪問・policy・推薦用の乱数streamを分け、初期状態と乱数の対応を明示する。
5. **新規性を検証するoutcomeを追加。** 個人ごとの行動shareの持続・creator/supporter間の遷移、対象別消費entropy、直近窓の反応格差、creator交代、提示1回当たり反応率を測る。役割分化が単なる初期フォロワー格差の反映かも確認する。
6. **構造と時間尺度の頑健性。** degree保存ランダム化、複数network seed、複数population size、L×access_prob、state境界、報酬の混合比、η/γ/τ/初期Qを検討。γは訪問単位、投稿寿命は全体step単位なので、access_probの変更は単純な時間換算にならない。
7. **持続効果を主張する段階で動的ネットワークを戻す。** 推薦オン→オフ、オフ→オンを比較し、プロフィール記憶・Q記憶・フォロー記憶を個別にリセットする。静的ネットワークは診断に有用だが、フォロー経由の履歴効果は評価対象から外れる。
8. **実証照合。** 投稿間隔と受信報酬の関係、作者別反応分布、投稿寿命、個人の行動構成等、複数の独立パターンを使う。探索に使うseedと確認用seedを分け、再現条件を固定する。

まずは「For Youが適合度を上げると同時に反応の集中を強めるのは、順位付け・再提示・ユーザー学習のどれによるか」を中心仮説にすると、現コードとの距離が小さく、反証可能である。
