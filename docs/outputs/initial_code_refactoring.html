[Fix 002] Adjacency Matrix Architecture Refactor

AdminOptim.java | Architecture / Performance

private double[][] W;
public void setFollowerNumArray() {
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++)
            if (this.W[i][j] > 0.0) this.followerNumArray[j]++;
}
private Set<Integer>[] followees;
private Set<Integer>[] followers;
public void updateAdjacencyMatrix(int userId, int[] followedIds, int unfollowedId) {
    if (followedIds[0] >= 0) {
        followees[userId].add(followedIds[0]);
        followers[followedIds[0]].add(userId);
        followerNumArray[followedIds[0]]++;
    }
    // ... O(1) updates
}
Rationale: Replaced dense $N \times N$ matrix with adjacency lists. This improves memory efficiency and reduces graph update/traversal complexity from $O(N^2)$ to $O(1)$ or $O(\text{degree})$.
